GitResolve is an npm library and CLI tool built for recruiters and ATS pipelines that need to extract structured developer profiles from raw candidate submissions. Feed it a portfolio URL, a GitHub link, or a resume PDF — it returns a clean, typed result with the candidate's profile, owned repositories, contributions, and external references.

## How GitResolve works

GitResolve follows a five-stage pipeline to turn raw candidate inputs into structured profiles:

<Steps>
  <Step title="Classify the input">
    GitResolve identifies whether the input is a portfolio site, git profile, repository URL, resume PDF, resume URL, or LinkedIn link using [`classifyInput`](/api/classify-input).
  </Step>
  <Step title="Fetch page content">
    For URLs, GitResolve fetches rendered HTML using one of three [browser providers](/providers/overview): native `fetch` (fastest, no dependencies), Puppeteer (full JS rendering), or Browserless (Docker-based, great for CI/CD).
  </Step>
  <Step title="Extract git links">
    All GitHub, GitLab, and Bitbucket URLs are extracted from page HTML — both from `href` attributes and raw text. For resume PDFs, both text content and embedded hyperlink annotations are parsed.
  </Step>
  <Step title="Disambiguate ownership">
    The [disambiguation engine](/concepts/disambiguation) cross-references profile links with repo owners to determine which GitHub account belongs to the candidate — with a `high`, `medium`, `low`, or `none` confidence score.
  </Step>
  <Step title="Return a structured result">
    Every resolved candidate gets a [`ResolverResult`](/api/types) containing their profile, owned repos, contributions (PRs and issues), and external references. Multiple sources for the same candidate are merged into an [`AggregatedResult`](/api/types).
  </Step>
</Steps>

## Supported input types

| Input | Example | What GitResolve does |
|---|---|---|
| **Portfolio site** | `https://janedoe.dev` | Scrapes page for git links |
| **GitHub profile** | `https://github.com/janedoe` | Scrapes profile, discovers repos |
| **GitLab profile** | `https://gitlab.com/janedoe` | Scrapes profile, handles `/users/` routes |
| **Bitbucket profile** | `https://bitbucket.org/janedoe` | Scrapes profile page |
| **Repository URL** | `https://github.com/user/repo` | Scrapes repo page, resolves owner |
| **PR / Issue URL** | `https://github.com/user/repo/pull/42` | Extracts as a contribution |
| **Resume PDF** | `./resume.pdf` or HTTPS URL | Extracts text + hyperlink annotations |
